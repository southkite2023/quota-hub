# 2.0.0 通用功能与设置

本轮重组设置模块，源码版本为 2.0.0+19；现有公开安装包仍为 1.3.1+18。未改动余额接口、计费口径或凭据迁移。

## 入口与功能

- Android 首页右上角齿轮和底部设置按钮；Windows/macOS 首页齿轮；桌面 Ctrl/⌘+,。
- 通用：刷新设置、桌面开机启动、启动最小化、关闭后常驻或退出、窗口位置与大小记忆。
- 外观与无障碍：浅色/深色/跟随系统，中英文/跟随系统，增强对比度，减少动画；字体大小遵循系统。
- 余额账户：原有账户管理和组件选择，独立于通用设置；编辑后返回、桌面关闭或退出会保护未保存输入。
- 账户与安全：保留统一账号及账号安全入口；原生端可选系统身份验证应用锁。默认关闭，启用/禁用前均要求验证，锁定策略独立存入平台安全存储。取消、验证失败或安全存储读取失败均不放行。
- 隐私与本机管理：离开应用时隐藏金额、权限状态及系统设置入口、隐私政策/服务协议、清理更新下载、恢复默认外观。
- 帮助与反馈：内置 FAQ、官网指南、用户自行提交反馈，诊断摘要先预览再复制。摘要只包含软件版本、平台类别和显示设置，不读取或导出原始日志、账号名、地址、密钥和会话。
- 关于：运行时版本、原有更新功能、更新日志、官网、源代码和 MIT/第三方许可。

## 桌面行为

Windows 新增原生托盘：打开、设置、刷新、退出。macOS 沿用原生菜单栏。托盘建立失败时关闭窗口会退出，避免隐藏后无法恢复。菜单栏与托盘可以重新打开应用，锁定时须先解锁才能查看界面。

启动项仅在用户主动开启时配置。Windows 使用当前用户 Run 项，macOS 使用当前用户 `Library/LaunchAgents/com.yuashie.astracct.autostart.plist`，关闭时只移除此应用自己的条目；不修改系统级设置。移动安装位置后需重新关闭/开启启动项；系统登录项或后台策略仍可能阻止启动。默认关闭。

窗口布局保存到独立偏好存储；悬浮窗和最大化/最小化尺寸不会覆盖普通窗口尺寸。恢复时按当前显示器工作区域调整，避免停留在已拔除的屏幕上。关闭时保存布局失败不会阻止退出。

快捷键：Ctrl/⌘+, 设置；Ctrl/⌘+R 刷新；Ctrl/⌘+Shift+H 隐藏/显示金额；Esc 返回普通窗口。

## 安全与边界

- 应用锁只保护本软件界面，不替代设备锁屏或凭据权限。验证中不会因系统验证窗口夺取焦点而反复触发锁屏。
- Android 桌面小组件为独立的系统展示面；根据需要隐藏金额或移除小组件。自动隐藏同步更新现有金额展示。
- 隐私开关与通用设置和余额账户库分离。恢复默认外观只重置主题、语言、对比度、动画，保留应用锁、账户、登录、后台策略和窗口偏好。
- 清理仅删除应用临时目录下 `astracct-updates` 内的普通下载文件，不遍历符号链接；不清理账户、登录、余额缓存或安装助手目录。下载/安装进行中不允许清理。
- 原生应用锁依赖设备已配置的系统验证。Web 不显示可用的系统应用锁开关；iOS 目前仍为 PWA/演示路径，不能将原生编译成功称为 iOS 原生产品已发布。
- Android 原生最低版本提高为 API 24（Android 7.0），并配置 FragmentActivity、AppCompat 启动主题与生物识别权限。
- 本轮语言设置覆盖通用设置及主要操作；网站、服务商返回的信息及远端更新说明沿用来源语言。
- 大字体、英文及深色模式已加入布局回归；真实读屏、系统身份验证交互、真机权限与登录启动仍需按平台人工验收。

验证记录见更新日志。源码完成、构建检查、真实设备验收及公开发布分别记录。
