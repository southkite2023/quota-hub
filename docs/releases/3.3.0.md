## 3.3.0 — 2026-10-30

类型：账号云端同步功能。状态：3.3.0+23 公开测试版已发布。

- 登录 Yuashie 后自动恢复同账号的账户参数、Key、订阅地址与云平台凭据；前台各端定期同步，失败后重试。历史未上传账户不自动归属其他账号，需主动重新保存。
- 保存时经 HTTPS 上传，复用服务端按用户隔离的 AES-256-GCM 加密存储；本机沿用凭据存储。不是端到端加密，服务端在鉴权后解密返回。
- 切换账号立即隐藏上一账号凭据，丢弃过期下载；删除云端账户同步删除，防止自动恢复已移除账户。未上传账户仍只从本机移除。
- 同步失败保留当前账号本地缓存，不把失败显示为同步成功。多端同时修改同一账户以服务端最后成功写入为准。
- 验证：客户端静态检查、155 项测试（含跨端模拟及切换账号竞态）和服务端 2 项加密/隔离集成测试通过；各平台安装包已发布，七个官网镜像摘要核对一致；原生构建 41015189985、发布验证 41016121722 通过。真实厂商设备长期运行未验收；macOS 未签名公证。
