# 星账 Astracct 1.1.0 — macOS 节点订阅测试版

本次仅提供 macOS 发行包（Intel x86_64 + Apple Silicon arm64 Universal），Android 公开正式下载入口暂仍指向 1.0.0。此 Release 为测试版本，不代表 Apple 公证或 App Store 上架。

### 本次新增
- 在「管理 / 添加余额账户」选择 **节点订阅 → 订阅链接 · 流量查询**，粘贴与 Clash / Shadowrocket 相同的 HTTPS 订阅链接。完整链接可能带有访问令牌，只保存在本机 Keychain；编辑时默认隐藏，确认框只显示订阅域名。
- 从服务商的 `subscription-userinfo` / `x-subscription-userinfo` 响应头读取流量使用情况：剩余流量、已使用流量、总流量及可用时的到期日期。总流量为零或缺失到期时间不冒充已知可用额度。
- 主窗口与悬浮窗显示节点指标；**macOS 顶部菜单栏**现在也可以单选展示剩余流量等项目，支持隐藏数值、失败状态与自动刷新。
- 沿用旧 macOS 的 `com.yuashie.astracct`、原 Keychain 配置标识和菜单栏功能；不覆盖已有账户数据。

### 使用方法
1. 下载 `astracct-1.1.0-macos-universal.zip`，解压后获得 `Astracct.app`。
2. 在 Mac 打开星账，在「管理 / 添加余额账户」选择节点订阅，然后粘贴 HTTPS 订阅链接并验证。
3. 在主界面查看流量；可在「菜单栏显示」下拉菜单选择节点的剩余流量，或在账户管理中勾选悬浮窗。
4. 关闭窗口后菜单栏仍可工作，主动退出应用后刷新停止。

### 限制与安全说明
- 只有服务商返回标准流量响应头时才能自动查询；不解析节点列表或订阅正文，不能保证支持所有机场，也不会连接/启用 VPN。
- 默认不自动跟随重定向；Cookie 登录或服务商私有 API 暂不支持。机场账户中的人民币余额通常无法从订阅链接得到。
- 本发行包未配置 Apple Developer 分发签名与公证，macOS Gatekeeper 可能拦截；建议仅从本仓库下载，不建议关闭系统全局安全检查。
- 自动测试使用模拟响应；真实服务商、网络环境和用户电脑上的长期运行仍需验证。不要在公开 Issue 中上传订阅链接或 Token。

构建和验证来源见 GitHub Actions 中的 **Publish macOS 1.1.0 preview (one-time)** 工作流；压缩包 SHA-256 记录在随附的 `SHA256SUMS.txt`。
