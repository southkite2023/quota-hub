# 1.3.1 · macOS 登录凭据修复测试版

修复 macOS 登录 Yuashie 账号时出现「无法安全保存登录凭证，请检查系统安全存储」。

- 登录会话使用应用专属的系统登录钥匙串，适配直接分发的 macOS 应用；继续加密保存，不改用明文文件或偏好存储。
- 会话保存、下次启动恢复和退出删除采用同一套配置；余额账户及其凭据保持不变。
- macOS 更新后需重新登录一次，无需清除余额数据或重建账户。
- 增加登录存储缺少 entitlement 的回归测试；Windows/macOS 原生检查同时覆盖登录凭据和余额凭据的真实写入、读取与删除，使用独立合成 key，不接触用户会话。

版本为 1.3.1+18。125 项客户端测试、静态检查及原生构建结果以发行前校验的对应提交为准。源码及构建：[7b6ac047](https://github.com/southkite2023/quota-hub/commit/7b6ac0471bfd1efa0a903c8638daaa2a40bc7195)、[原生构建](https://github.com/southkite2023/quota-hub/actions/runs/38691546153)、[客户端验证](https://github.com/southkite2023/quota-hub/actions/runs/38691546246)。

提供 Android 固定签名 APK、Windows x64 完整 ZIP 和 macOS Universal ZIP，以及 SHA256SUMS.txt、packages.json、apk-report.json。Android 保持现有包名和固定签名。旧版本及附件保留。

仍为公开测试版：macOS 未进行 Apple 分发签名与公证；用户设备的真实账号重新登录、厂商真机和长期运行仍待验收。Linux 无公开包，iOS 使用 PWA。可以在应用设置中检查更新；官网优先提供校验后的服务器下载。
