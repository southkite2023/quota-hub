# 星账 Astracct 3.0.0+20 · 全端 UI 与 Mac 本地凭据公开测试版

参考 FlClash 的页面结构，独立实现桌面侧栏、手机底部导航、圆角账户卡片和统一的浅色蓝色/深色暖橙主题。保留余额查询、账户编辑、悬浮窗、菜单栏/托盘、金额保护及应用内更新。包含 2.0.0 开发候选的统一设置中心和通用功能。

macOS 账户密钥、登录会话和应用锁策略改为保存在本机用户数据目录的明文文件，目录 0700、文件 0600。首次迁移旧钥匙串记录可能需要一次系统授权，迁移成功后不再为这些记录调用钥匙串；迁移失败保留原配置并提示错误。文件权限不能隔离同一系统用户运行的其他程序，应用锁仅保护界面访问。Android/Windows 沿用原有系统凭据存储。

- Android：通用、ARM64、ARMv7、x86_64 四种 APK，版本 3.0.0、构建号 20，沿用 com.yuashie.astracct 与既有固定签名；最低 Android 7.0。
- Windows：完整 x64 ZIP，解压后运行 astracct.exe，保留 DLL 与 data 目录。
- macOS：Intel + Apple Silicon Universal DMG，打开后将 Astracct 拖到 Applications，复制完成后从“应用程序”启动，在桌面右键磁盘选择“推出”。另保留 ZIP 用于应用内更新。尚未配置 Apple 分发签名和公证。
- iOS：继续提供网站上的手动记录 PWA，不提供原生 IPA，也不宣称支持厂商 API 自动查询。

源码本地静态检查、146 项 Flutter 测试和 Web 构建通过。发布流程要求同一源码的客户端检查、服务端检查和三端原生构建全部通过，核验不可变产物摘要、APK 版本与固定证书，并使用真实候选包验证 Windows/macOS 更新替换、重启和失败回退后才公开附件。精确源码与构建运行见 provenance.json，文件大小与 SHA-256 见 packages.json / SHA256SUMS.txt。

真实用户设备的密钥迁移、身份验证、升级保留、小组件、多屏和长期后台行为仍需验收。旧版无需卸载；卸载会删除本机数据。各平台实际下载与镜像状态以 https://yuashie.cn/projects/001/download 为准，镜像同步完成前可从本页下载。
