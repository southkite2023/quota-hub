# Astracct 1.3.0+17 · 公开测试版

Android、Windows、macOS 统一加入应用内更新：在「余额账户设置 → 应用更新」检查当前平台最新版本，查看说明，从 yuashie.cn 下载并验证 SHA-256 后确认安装，无需登录或白名单。已使用旧版本的用户需要先通过官网下载一次 1.3.0，此后即可使用应用内更新。

Android 在系统安装前额外校验包名、递增构建号和固定签名；首次使用需要授权允许安装。Windows/macOS 会退出、备份旧程序、替换并重新打开，替换失败恢复旧文件，账户凭据继续保存在本机安全存储。桌面应用目录需要写入权限；Windows 请首次完整解压 ZIP 再运行。macOS ZIP 支持 Intel / Apple Silicon、macOS 12+，仍未配置 Apple 分发签名与公证。

包含此前开发的 HTTPS 节点订阅响应头流量查询与 Yuashie 统一账号入口。账号登录不等于余额配置云同步，不上传本机 API Key、云密钥或订阅链接。第三方和短信登录的开放状态以服务器配置为准。iOS 使用官网 PWA，联网重新验证页面资源；设置提供重新载入入口。当前没有 Linux 安装包或原生 iOS 分发包。

源码 `b4b4c4c27d27fa09d4f1f62dd4909ea5062dca53`。Flutter 分析、123 项测试、Web 构建、Android 固定签名与原生构建、Windows/macOS 窗口/安全存储检查及 iOS 模拟器构建均通过。发布流程还使用真实桌面候选包在临时安装目录验证替换、重启、备份和故障回退。macOS 在固定 Flutter 3.47 SDK 下使用官方支持的 Skia 后端，规避悬浮窗缩放时发现的 Impeller 崩溃。

安装包来自原生运行 `38687215325` 的已校验不可变产物；随附 `SHA256SUMS.txt`、`packages.json`、`apk-report.json`。真实厂商设备升级、用户 Mac 首次打开、真实服务商 API 与长期后台行为仍待验收，不能将本测试版视为全面完成正式验收。

官网下载：[yuashie.cn](https://yuashie.cn/projects/001/download)。服务器每十五分钟同步公开版本，完整安装包验证后才更新网页与应用共用的清单；GitHub 保留备用下载。
