# AstrAcct / Yuashie 统一账号（1.2.0 开发候选）

软件设置顶部的 Yuashie 账号与 yuashie.cn 使用同一用户、密码与会话库。软件内的“注册”打开统一注册页，在此创建的账号可以登录网站，网站账号也可以直接登录软件。

- 未启用验证码时，软件提供邮箱/手机号和密码表单；当前仅开放邮箱账号，手机号需后续号码验证服务。
- 启用阿里云验证码 2.0 后，点击登录打开系统浏览器，在统一登录页输入账号和密码并完成验证，再点击“确认登录 AstrAcct”。软件自动领取结果。
- 第三方提供 QQ、GitHub、Google。没有申请完成的服务显示待开通。已有网站账号应先登录网站“账号安全”，绑定第三方身份，避免另建账号。
- 浏览器授权使用 SHA-256 challenge 与只保留在软件内的随机 verifier；请求 10 分钟过期且单次领取。网址不包含会话令牌或密码。软件令牌保存到系统安全存储，退出会撤销服务器会话并清除本机令牌。
- 邮箱发送与短信发送未接入，当前不开放邮箱/手机号归属验证和自助重置密码。阿里云验证码 2.0 仅验证是否真人，不能取代号码归属验证。
- 登录不会上传或同步已有的厂商 API Key、云密钥、订阅链接与余额配置；仍沿用本机安全账户库。原生端用户身份与余额查询账户是不同概念。

服务端配置、第三方平台申请与回调地址见 [Netweb 统一账号说明](https://github.com/southkite2023/Netweb/blob/main/docs/UNIFIED-ACCOUNTS.md)。服务地址固定为 `https://yuashie.cn`；网页客户端应同源托管，未开放跨站 CORS。iOS 公开网页版本由 Netweb 的独立 PWA 提供。

本地验证：Flutter 3.47.5 静态检查、119 项测试与 Web 构建通过。macOS 本地命令行工具默认 SDK 与 linker 不匹配时，本轮测试仅通过临时 xcrun 路径选择现有 macOS 26.5 SDK，未修改系统 SDK 或依赖源码。原生 CI、真实第三方授权及验证码验收需配置与设备验证后确认。
